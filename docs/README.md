# Luma Drift documentation

**Play, understand the system, inspect the evidence, and decide what to build next.**

Two artifacts coexist: the signed **stable 1.1.0 offline game** and the separate **1.2.0-sandbox Lab**. Current source builds the Lab, with a different application ID/private wallet, 24 companions, clearer local events and optional test commerce/identity surfaces. The stable captures and validation remain scoped to 1.1; they do not certify the new Lab SDKs or a live Google login.

**[Download Lab APK](../releases/luma-drift-1.2.0-sandbox.apk)** · [Preserved stable APK](../releases/luma-drift-1.1.0.apk) · [Package evidence](VALIDATION.md). The main README includes a separate gallery of actual Lab captures; Google identity remains unconfigured and real checkout disabled.
