# Luma Drift documentation

**Play, understand the system, inspect the evidence, and decide what to build next.**

The signed **stable 1.1.0 offline game** and separate **Lab sandbox** coexist. Delivered Lab 1.2 has its own package, captures and evidence. Current source builds delivered **Lab 1.3.0-sandbox**, an update to that same Lab wallet with a measured 480-board sequence, action allowance and six powers. Its recorded final-binary Android 16 cases passed, including two actual test-ad rewards; the test progression/inventory profile was explicitly synthetic and restored afterward. Stable captures and historical 1.2 results do not certify changed 1.3 routes or a live Google login.

**[Download Lab 1.3 APK](../releases/luma-drift-1.3.0-sandbox.apk)** · [Preserved Lab 1.2](../releases/luma-drift-1.2.0-sandbox.apk) · [Preserved stable APK](../releases/luma-drift-1.1.0.apk) · [Package evidence](VALIDATION.md).
