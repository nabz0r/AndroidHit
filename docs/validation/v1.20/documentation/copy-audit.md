# Active 1.20 currency/energy copy audit

The active README, roadmap, release, UX/menu and evidence-index copy now separates four values: earned LumaCoins; production account LumaGold or isolated Lab test Gold; ten-unit session energy; and attempt-local companion Charge starting at 3/capped at 6. New-attempt costs explicitly include daily/weekly, Remix and expedition modes alongside campaign U11+. The equipped appearance is not called the team captain unless those selections actually match. Gift text states that reveals wait for explicit closing.

The staged `prepare-site-v120.py` was read without editing it or `public/`. Before final website preparation, the root should consider these remaining copy points:

1. **“LumaGold: a separate account wallet”** does not by itself explain premium origin or the Lab test exception. Suggested meaning: account premium currency, never an earned-puzzle reward; Lab Gold is a separate test balance. Do not imply that real checkout or the refill is already activated.
2. **“Session energy: separate from talent charge”** separates names but omits the visible pacing rule. A short note or linked explanation should say10 maximum, +1 per 10 minutes, one per eligible new attempt, and free introductory/practice exceptions. A victory or resume is not another charge.
3. **“charge des talents / talent charge”** should match the app's capitalized **Charge**, with3 at attempt start and6 maximum when explained. It is not replenished by the premium session-energy pack.
4. The gallery remains a browsable catalogue, not proof that every shown identity is owned. In-app E uses **Companion arrivals / Arrivées compagnons** for the random acquisition pool rather than “My companions”. Keep that ownership distinction in future screenshots/captions.

These are documentation/template wording findings. No app, staging script, public page, wallet or provider was changed by this audit. Final E native media and root acceptance remain required before website generation.
