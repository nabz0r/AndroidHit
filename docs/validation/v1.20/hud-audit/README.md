# Puzzle wallet input audit — preserved E witness, accepted F correction

This is **pure geometry and read-only source evidence**, not a native reproduction. The [report](report.json), original [probe](HudAudit.java) and [output](geometry-output.txt) preserve the E finding. The three actual layout helpers were compiled only into a temporary directory; their hashes still match the frozen E record. No target application or device was changed by this probe.

For a 320×480 pixel window at density 1, top/bottom insets 24/24 and font scale 1.3, the live helpers produce viewport 526.5, boardY 383.75, content height 875.6825 and maximum scroll 349.1825. The board can therefore start at 34.5675, beneath the fixed wallet's 0–42 band. An equivalent 480×720/density 1.5 input has the same logical geometry. The measured feedback input 42 is the caller's guaranteed floor; it is not a fabricated native glyph measurement. At 480×800/density 1.5 the same probe leaves the board at 99.5675, outside the wallet.

On E, `ACTION_DOWN` first finds the topmost wallet hit but also selects a piece from board geometry. `ACTION_UP` handles a piece-direction swipe before the wallet's no-op action. For U11's 5×5 board, logical down (144,38) lies in row 0/column 1/action 2 underneath the wallet; up (144,10) is a 28-unit upward gesture, matching that piece's direction. The published U11 certificate identifies that tile and direction. This establishes a reachable input-routing risk from the source and geometry, not an observed Android gesture.

F adds a guard preventing board selection when a puzzle gesture begins at `y<42`. It changes neither layout nor awards. Exact F now passes its own [native wallet-swipe report](../native/candidate-f-tiny-wallet-swipes/report.json):16 actual four-direction swipes, including an observed piece/HUD intersection after resetting scroll before each swipe, leave run/history/budget/Undo/team/currency state unchanged. Its [final index](../native/candidate-f-final-index.json) includes that scope. Six original FR/EN home/shop/victory images are also [recorded](../../site-v1.20/native-capture-map.json). E's existing grades/skill reports remain E evidence; they are not renamed as F runs.
