## Three implemented changes

1. **Companions act during U puzzles.** All 37 current identity definitions map to six bounded role families: GUIDE highlights a certified safe action; VISION highlights local legality without claiming solvability; TRAIL previews safe actions; PULSE/FLOW execute certified exits through the actual move budget; REWIND restores real history with the normal refund limits. These are six effect engines with identity parameters, not 37 unique mechanics. [Rules and exact parameters](GAMEPLAY_1_19.md).
2. **The portrait reacts to actual play.** The board dock uses the chosen companion, current form, selected style and presented wardrobe. Successful actions, a blocked gesture, gate changes and skill activation choose existing emotional/stance/jump frames. Brief role feedback is clipped to the board and respects reduced motion. This reuses the existing authored art; it does not add 37 new animation sets or claim that every costume attachment has been fitted. [Presentation contract](design/v1.19/BATTLE_ART_DIRECTION.md).
3. **An owned squad makes choices visible.** Select one to three distinct owned companions, captain first, with an explicit save. Changes apply to the next board; appearance equipment remains separate. Two used skill families enable one explicit Resonance action, so three companions are optional. Team edits do not spend currency, grant ownership or consume items. [UX and persistence](UX_1_19.md).

Each attempt starts with **3 shared energy**, capped at **6**. Each distinct exited piece adds one energy, including automatic exits; an undo/re-exit cannot add more for the same ID. Each companion uses its talent once in the attempt. Resonance costs no extra energy, while its real exit still consumes the usual board action. Inventory powers remain separate. Outfits change the look; skill identity comes from the companion. Existing expedition route skills remain distinct from the puzzle role system.

The new commands are bounded to U progression-v6 Journey/expedition boards, while the U1–U1000 geometry, ordinary movement rules, historical content identities, earned economy, inventory and provider gates are retained. Real checkout and paid premium draws remain closed, and ads remain test ads. Google sign-in does not synchronize local progression, house, wardrobe or squad.
